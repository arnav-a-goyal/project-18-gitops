# Project 18 - GitOps Infrastructure Deployment

## Goal
Trigger infrastructure updates from PR merges.

## Workflow
1. Create a feature branch.
2. Push changes.
3. Create a Pull Request.
4. GitHub Actions validates Terraform.
5. Review and approve the PR.
6. Merge into main.
7. GitHub Actions waits for deployment approval.
8. Terraform Apply runs.

## Tools
- VS Code
- Git
- GitHub
- GitHub Actions
- Terraform

## Deliverable
Successful workflow run screenshot.
